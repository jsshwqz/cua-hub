## 4. 环境坑（本机 Windows，实测）

1. **git push 需显式代理**：`https_proxy=http://127.0.0.1:10808 git push …`——gh 走系统代理能通，git 不走会 `Recv failure: Connection was reset`。
2. **D 盘空间**：646G 盘被多 agent 并行构建吃得只剩个位数 GB。共享 target（`D:/cargo-target`）被多 agent 锁竞争；**独立 target 用 `-j 1` 降链接峰值**；每轮构建前 `df -h /d` 低于 3G 先清 `incremental/`（可再生）。
3. **exe 锁**：任何 agent 起过 `innoforge-server.exe` / cua-hub 二进制，同名二进制的链接就过不去（拒绝访问）——起 server 用独立 target 或结束即回收。
4. **门禁三件套**：`cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --workspace`——本分支实测 rc=0（cua-io 20/20）。
