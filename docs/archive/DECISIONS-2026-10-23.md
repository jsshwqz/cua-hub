- 「我是想把这个做成 MCP 或 skill 或其它，是能让 agent 来操作使用的」→ 定位：能力以 MCP 工具/技能交付，不是库。

- **「我要的目标是这个操控电脑的能力，这是最终目标。别搞混了。」** → 最高准绳：交付可复用操控能力，演示产物不是目标。
- 「从这个 freecad 的操作来看，你进步在哪，是否有必要升级一版？」→ 要求以能力增量衡量版本。
- 「等 P0 吧」→ 未做完关键可靠性前不发版。
- 「可以，开始 P0 吧」「先开始做建议里的 1、2、3」「按你建议做」→ 批准 P0、P1、P2 的范围。
- 「行，发布吧，但版本号不想跳变这么大，你根据仓库现状来发布」→ 版本策略：延续 0.1.x，不跳号。
